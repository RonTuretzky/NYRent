# Third-party components

- ENS Contracts 1.7.0: MIT. DNSSEC and utility sources are imported from the pinned npm package; their source license headers are retained.
- OpenZeppelin Contracts 5.6.1: MIT. RSA, P-256, math and base64 primitives are imported from the pinned npm package.
- ethers 6.17.0: MIT. The browser distribution is copied without altering its code or license header to `web/vendor/ethers.min.js`.
- dnspython 2.8.0 and dkimpy 1.1.8: optional independent verification and DNS proof collection tools. Their licenses remain in the installed Python packages; these packages are not bundled in the deliverable archive.
- Cover photograph: Keenan Constance, [Unsplash photo](https://unsplash.com/photos/brown-brick-building-with-red-metal-window-grills-LKg5hcC9Xqo), used under the Unsplash license. The photograph is illustrative and is not rent-price evidence.

No real publisher email or private test signing key is bundled as an original newsletter. Every supplied `.eml` fixture is labeled synthetic.
